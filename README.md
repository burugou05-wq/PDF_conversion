# 画像 → PDF 変換ツール v2.0

Windows向けデスクトップアプリです。手動選択・フォルダ一括変換、順番変更、検索、プレビュー、ドラッグ＆ドロップに対応します。CLIからも同じ変換エンジンを利用できます。

今回の変更内容は [更新履歴（一般ユーザー向け）](CHANGELOG.md) をご覧ください。

## EXEのダウンロード（一般ユーザー向け）

[GitHub Releases](https://github.com/burugou05-wq/PDF_conversion/releases/tag/v2.0.0) の「Assets」から 画像PDF変換ツール.exe をダウンロードして起動してください。Pythonのインストールやビルドは不要です。

旧版から更新する場合は、旧版を終了してから新しいEXEに置き換えてください。コード署名はありません。警告が出た場合は入手元を確認し、セキュリティソフトが危険と判定したファイルは実行しないでください。検証状況と制限は [更新履歴](CHANGELOG.md) をご確認ください。

## 動作環境

- Windows 10 / 11、64bit
- ソース実行・ビルド: Python 3.10〜3.12（推奨3.11）
- EXE利用時: Pythonのインストール不要
- CLIと変換テストはLinuxでも実行可能。GUIにはTkとディスプレイが必要です。

## セットアップと起動

PowerShellでこのフォルダを開き、次を実行します。仮想環境のactivateは不要です。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# AVIF/HEIFとドラッグ＆ドロップを使う場合
.\.venv\Scripts\python.exe -m pip install -r requirements-optional.txt
.\.venv\Scripts\python.exe img2pdf_app.py
```

基本対応形式: JPEG / PNG / WebP / BMP / GIF / TIFF。
AVIF対応はPillowの機能または追加プラグイン、HEIF/HEIC対応は追加プラグインが必要です。利用できない形式は理由付きでスキップされます。

## 操作

1. 「手動選択」で画像・フォルダを追加するか、「フォルダ一括」で対象フォルダを選択します。
2. 手動選択では上へ・下へ・先頭へ・末尾へ、またはリスト上のドラッグで順番を変更できます。
3. リスト／グリッド、検索、プレビューで確認します。グリッドは48件ごとのページ表示です。
4. 画質・用紙・余白・透過画像の背景色を選びます。
5. 出力先の `.pdf` パスを指定して「PDFに変換」を押します。

- 検索は表示の絞り込みのみです。PDFには一覧の全画像が入ります。
- 検索中の削除・移動は選択したファイルに作用します。非表示のファイルも含む全体順序を変更します。
- フォルダモードの並び順: `name`=名前、`number`=自然な数字順、`date`=更新日時の新しい順。
- サブフォルダは対象外です。
- 複数ページTIFF、アニメーションGIF/WebP等は全フレームをページ化します。
- 壊れた入力はファイル単位でスキップし、完了時に理由を表示します。途中フレームが壊れた場合、そのファイル全体をスキップします。

## 画質と用紙の仕様

### 元画質優先

- 透過なし・向き補正不要の単一JPEG/PNGは直接取り込みます。JPEGの圧縮データは保持されます。
- その他の画像はデコードし、EXIF方向を補正、必要に応じて背景合成してPNGへ変換します。
- 用紙サイズと余白のために画像を再圧縮することはありません。PDF上の配置サイズで調整します。
- 「すべてのメタデータ・色・ビット深度を完全保存」するモードではありません。変換する画像はRGB化され、ICC色変換は実装していません。

### 軽量化

- PDF上の表示寸法に対して最大150dpiへ縮小し、JPEG品質85で保存します。拡大しません。
- 画像内容によってはファイルが小さくならない場合があります。

### 用紙と余白

- A4 / A3 / Letterの物理寸法をPDFのポイント座標で設定します。
- 画像は中央配置し、余白内に収めます。元の物理寸法より大きく拡大しません。
- 横長画像の用紙自動回転は解除できます。
- 「元のサイズ」では元画像のDPIを参照し、不正・不明なら96dpiとして計算します。
- 余白は0〜100mmです。背景色は画像の透過部分への合成色であり、PDFの余白は通常白表示です。

## 保存・キャンセル

出力先と同じフォルダに一時ファイルを保存し、完成してから公開します。既存PDFの上書きは明示確認が必要です。キャンセルや保存失敗では既存PDFを置き換えません。

上書きなしの公開にはハードリンクを使用するため、NTFSなど対応ファイルシステムが必要です。非対応の保存先ではエラーになります。安全性を優先し、直接書き込みへのフォールバックは行いません。

キャンセルは画像・フレーム間と保存前に確認します。実行中の画像デコードやPDF書き込みを強制中断しないため、反映まで時間がかかる場合があります。

## EXEビルド

```powershell
.\.venv\Scripts\python.exe build.py
```

テスト・コードチェック成功後、共通の `ImageToPDF.spec` でビルドします。
出力: `dist\画像PDF変換ツール.exe`。
`build.ps1` はこのスクリプトを呼ぶだけのラッパーです。

既に依存を入れている場合は `build.py --skip-install` を使えます。
ビルドはWindowsで行ってください。配布前にPython未導入のWindowsでも起動・変換・DnDを確認してください。

## CLI

```powershell
.\.venv\Scripts\python.exe cli.py image1.jpg image2.png -o result.pdf --page A4 --margin 10
.\.venv\Scripts\python.exe cli.py .\images -o result.pdf --quality compact --overwrite
```

終了コード: `0`=成功、`1`=失敗、`2`=一部スキップして成功。

## 開発・テスト

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
```

CIはWindows/LinuxのPython 3.11/3.12でテストし、Windows EXEをartifactとして生成します。
直接依存は固定しています。完全な推移依存ロックではありません。

構成:

- `img2pdf_app.py`: GUI、キュー経由の非同期通知
- `file_model.py`: ファイル探索・選択・順番変更
- `image_processor.py`: ヘッドレス変換、PDF配置、安全な保存
- `ui_theme.py`: テーマ
- `cli.py`: CLI
- `app_config.py`: 名前・バージョン
- `tests/`: 選択操作、用紙寸法、画像処理、キャンセル、保存失敗の回帰テスト

## 制限・運用

- 自己更新機能は削除しました。配布元から新しいEXEを手動で取得してください。
- 画像前処理は逐次実行し、巨大画像の同時展開を避けます。ただしPDF結合のオブジェクトはメモリに保持されるため、無制限の大量画像処理を保証しません。
- 画像パーサーの安全性のため、Pillowの巨大画像保護を無効にしていません。
- ログ: Windowsでは `%LOCALAPPDATA%\ImageToPDF\app.log`。画像パスや失敗理由を含むため、共有前に内容を確認してください。
- 配布ライセンスはこのリポジトリでは指定していません。公開配布する場合は権利者が決定し、依存ライブラリの条件も確認してください。
